# Olympus holes 1-9: notes from the Jomez MPO R1F9 first-person fly-throughs

Source: https://www.youtube.com/watch?v=YkaPk2PR9cM (chapters: H1 0:39, H2 5:37, H3 10:00, H4 13:49, H5 18:38, H6 22:43, H7 25:26, H8 29:13, H9 32:28).
Each hole opens with a ~20 s first-person fly-through (overlay: hole, par, distance, MPO layout map). Sampled every ~3 s (6-8 frames/hole, 0.35 scale);
the heights/tree spots in tools/olympus_spec.py are visual estimates, not surveyed. Red layout (101-109) reuses the same STYLE.
